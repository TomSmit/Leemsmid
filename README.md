# leemsmid.nl

Statische website van Leemsmid, gehost via GitHub Pages.

* `index.html`: de hele site (stijl en script staan in het bestand zelf)
* `img/`: foto's
* `fonts/`: lettertypes, lokaal gehost (geen Google Fonts, AVG-vriendelijk)
* `CNAME`: het eigen domein
* `robots.txt` en `sitemap.xml`: voor zoekmachines. Pas `lastmod` in de sitemap aan bij grote wijzigingen.
* Werken staan in de lijst `WORKS` in `index.html`. De korte lijst in `<div id="hang">` is de versie zonder JavaScript voor zoekmachines; houd die gelijk met `WORKS`.
